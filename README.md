# Portfolio — Ariel Aloukou

Site portfolio personnel d'**Ariel Jean Levi ALOUKOU**, étudiant en Licence 3
réseaux et télécommunications à l'Institut Ivoirien de Technologie (IIT),
orienté infrastructures, cybersécurité et développement logiciel.

Le site présente mon parcours, mes compétences et une sélection de projets
réalisés, avec un contenu strictement vérifiable : chaque projet exposé pointe
vers son dépôt GitHub.

## Stack technique

- **Next.js 16** (App Router) · **React 19** · **TypeScript**
- **Tailwind CSS 4**
- **Framer Motion** (animations)
- **GSAP** (effet magnétique des boutons)
- **Three.js** + React Three Fiber (scène 3D du hero)
- **Lenis** (smooth scroll)
- **Radix UI** (accordéon FAQ)
- **lucide-react** (icônes)

## Démarrage

Installer les dépendances :

```bash
npm install
```

Lancer le serveur de développement :

```bash
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000) dans le navigateur.

Build de production :

```bash
npm run build && npm start
```
